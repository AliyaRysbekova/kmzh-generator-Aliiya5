Сабаққа арналған қосымшалар

Толық тапсырма мәтіндері, оқушыға берілетін материалдар, ЖИ промпттары және жауап кілттері.

ҚМЖ жасау — сынақ режимі

GitHub нұсқасында сервер әзірге қосылмаған. Төмендегі промптты көшіріп, ЖИ-ге жіберіңіз, содан кейін JSON жауабын осында қойыңыз.

ChatGPT ашу Gemini ашу
Маңызды: жоғарыдағы промптты ChatGPT немесе Gemini-ге жіберіңіз. ЖИ нақты сабақ жоспарын жазып болғаннан кейін, оның соңғы толық JSON жауабын көшіріп қойыңыз.
«JSON құрылымы», үлгі код немесе ішінде ... тұрған шаблонды қоймаңыз — оның орнына нақты мұғалім әрекеттері, тапсырмалар және жауаптар болуы керек.
